About the EV Price Prediction System

A comprehensive machine-learning web application for electric two-wheeler valuation in Pakistan.

1. Project Overview & Motivation

The automotive sector in Pakistan is currently undergoing a structural energy transition toward electric two-wheelers (scooters and motorcycles) driven by domestic fuel costs, urban emissions targets, and favorable import/assembly policies. However, the commercial EV landscape in Pakistan is fragmented, featuring emerging domestic assemblers (such as Vlektra, Evee, MS Jaguar, Metro, Okla, Crown, and Jolta) offering wide variations in battery technologies (Lithium-Ion, LiFePO4, Graphene) and motor powers.

This project implements an end-to-end full-stack machine learning solution to model EV prices in Pakistani Rupees (PKR) as a function of 10 verifiable physical and electrical specifications. It serves as an academic research prototype, university final-year project showcase, and professional DevOps portfolio artifact.

4. Machine Learning Methodology

1

Data Collection & Quality Auditing

Assembled 35 officially listed electric motorcycle and scooter models across Pakistani assemblers. Zero missing values and zero duplicate rows were verified.

2

Feature Engineering & Target Isolation

The model commercial name was deliberately excluded from predictors to prevent ID memorization. The continuous target price_pkr was isolated.

3

Candidate Model Benchmarking

Evaluated Linear Regression, Gradient Boosting, Extra Trees, and Random Forest using 5-fold cross-validation. Random Forest achieved the lowest out-of-fold MAE (PKR 64,112).

4

Pipeline Packaging & Serialization

Packaged the complete fitted preprocessing (imputer + one-hot encoder) and fitted Random Forest into a unified scikit-learn Pipeline and serialized with joblib.

5. Research Limitations & Responsible Use

Educational Research Disclaimer: This web application and machine learning model are provided strictly for educational and scientific research purposes. It is not an officially certified automotive appraisal or banking valuation tool.

Sample Size Limitation: Because the dataset comprises 35 vehicles, prediction variance can be elevated when evaluating atypical configurations, unlisted custom brands, or vehicles with extreme power-to-weight ratios.

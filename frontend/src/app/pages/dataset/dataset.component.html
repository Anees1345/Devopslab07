Data Preparation & Pipeline Preprocessing

Fitted using scikit-learn ColumnTransformer and serialized with joblib

Numeric Branch (7 Features)

Median Imputation

Features: range_km, top_speed_kmph, motor_watts, battery_capacity_ah, charging_time_hrs, warranty_months, curb_weight_kg.

Handled via SimpleImputer(strategy='median').
Categorical Branch (3 Features)

One-Hot Encoding with Unknown Handling

Features: brand, type, battery_type.

Handled via OneHotEncoder(handle_unknown='ignore') to gracefully accept unseen future brands.
Excluded Feature

Unique Model Name Exclusion

The model column contains 35/35 unique names (e.g. Retro 1969, Bolt, Benly e). It was intentionally removed from training to prevent memorization/overfitting and force the model to learn physical & electrical cost drivers.
